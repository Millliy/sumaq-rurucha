# Sumaq Rurucha

Sitio web base con estructura HTML, CSS y JavaScript.

## Estructura

- `index.html`: pagina principal.
- `catalogo.html`: catalogo de productos.
- `producto.html`: detalle de un producto.
- `carrito.html`: carrito de compras.
- `pago.html`: pago / checkout.
- `contacto.html`: pagina de contacto.
- `nosotros.html`: pagina institucional.
- `soy-distribuidor.html`: pagina para distribuidores.
- `buscador.html`: buscador del sitio.
- `css/styles.css`: estilos del sitio.
- `js/main.js`: scripts del sitio.
- `assets/img/`: imagenes del sitio.
- `assets/icons/`: iconos del sitio.
